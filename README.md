# skriptbox.com – tool sources

Free browser tools from [skriptbox.com](https://skriptbox.com). Each tool lives in its **own branch** with just its source
code – pick the one you need and download it via *Code → Download ZIP* on that branch.

| Tool | Description | Try it |
|---|---|---|
| [Password Generator](https://github.com/Radma99/skriptbox.com/tree/password-generator) | Generate strong passwords and passphrases for free – right in your browser, nothing is transmitted. | [Online](https://skriptbox.com/en/tools/password-generator) |
| [Text Counter](https://github.com/Radma99/skriptbox.com/tree/text-counter) | Count characters, words and sentences, estimate reading time and check lengths for Google and social media. | [Online](https://skriptbox.com/en/tools/text-counter) |
| [Resize & Convert Images](https://github.com/Radma99/skriptbox.com/tree/image-converter) | Resize photos for free and convert them to WebP, JPG or PNG – no upload, right in your browser. | [Online](https://skriptbox.com/en/tools/image-resizer) |
| [Lorem Ipsum Generator](https://github.com/Radma99/skriptbox.com/tree/lorem-ipsum) | Generate placeholder text for free – paragraphs, sentences, words or an exact character count, as text or HTML. | [Online](https://skriptbox.com/en/tools/lorem-ipsum-generator) |
| [Text Generator](https://github.com/Radma99/skriptbox.com/tree/text-generator) | Generate readable placeholder text in English or German – with headline, teaser and body text that fit the topic. | [Online](https://skriptbox.com/en/tools/text-generator) |
| [Favicon Generator](https://github.com/Radma99/skriptbox.com/tree/favicon-generator) | Create favicons from a logo or a letter – with favicon.ico, SVG, Apple and Android icons and HTML code as a ZIP. | [Online](https://skriptbox.com/en/tools/favicon-generator) |
| [Redirect Generator](https://github.com/Radma99/skriptbox.com/tree/redirect-generator) | Generate 301 redirects for .htaccess or nginx – checked for loops, chains and duplicates. | [Online](https://skriptbox.com/en/tools/redirect-generator) |
| [Table to HTML](https://github.com/Radma99/skriptbox.com/tree/table-to-html) | Convert tables from Excel, Google Sheets or CSV into clean, accessible HTML. | [Online](https://skriptbox.com/en/tools/table-to-html) |
| [JWT Debugger](https://github.com/Radma99/skriptbox.com/tree/jwt-debugger) | Decode JSON Web Tokens, verify signatures (HMAC, RSA, ECDSA, EdDSA) and create your own tokens – nothing is transmitted. | [Online](https://skriptbox.com/en/tools/jwt-debugger) |
| [URL Encoder & Decoder](https://github.com/Radma99/skriptbox.com/tree/url-encoder) | URL-encode passwords and text (like rawurlencode), decode them and build connection URLs like DATABASE_URL – nothing is transmitted. | [Online](https://skriptbox.com/en/tools/url-encoder) |
| [UUID & ULID Generator](https://github.com/Radma99/skriptbox.com/tree/uuid-generator) | Generate UUIDs (v4, v7, v5) and ULIDs for free – up to 1,000 at once as a list, JSON or SQL – and decode existing IDs. Nothing is transmitted. | [Online](https://skriptbox.com/en/tools/uuid-generator) |
| [Color Contrast Checker (WCAG)](https://github.com/Radma99/skriptbox.com/tree/contrast-checker) | Check color contrast against WCAG 2.2 – AA and AAA for text and UI components, with a live preview and color suggestions, right in your browser. | [Online](https://skriptbox.com/en/tools/contrast-checker) |
| [Unix Timestamp Converter](https://github.com/Radma99/skriptbox.com/tree/timestamp-converter) | Convert Unix timestamps to dates and back – seconds to nanoseconds, any time zone, with code for PHP, JavaScript, Python, SQL and Bash. | [Online](https://skriptbox.com/en/tools/unix-timestamp-converter) |
| [Base64 Encoder & Decoder](https://github.com/Radma99/skriptbox.com/tree/base64-encoder) | Encode and decode text and files as Base64 – UTF-8, base64url and data URIs for CSS and HTML, with validation and preview. No upload. | [Online](https://skriptbox.com/en/tools/base64-encoder) |
| [.htpasswd Generator](https://github.com/Radma99/skriptbox.com/tree/htpasswd-generator) | Create and verify .htpasswd files with bcrypt, APR1-MD5 or SHA-1 – including ready-made Apache and nginx config, nothing is transmitted. | [Online](https://skriptbox.com/en/tools/htpasswd-generator) |
| [JSON Formatter & Validator](https://github.com/Radma99/skriptbox.com/tree/json-formatter) | Format, minify and validate JSON online – with the exact line and column of each error, clear hints and key sorting. Nothing is uploaded. | [Online](https://skriptbox.com/en/tools/json-formatter) |
| [Hash Generator](https://github.com/Radma99/skriptbox.com/tree/hash-generator) | Calculate MD5, SHA-1, SHA-256, SHA-512 and CRC32 hashes for text and files, create HMACs and verify checksums – no upload. | [Online](https://skriptbox.com/en/tools/hash-generator) |

All tools run entirely in the browser; no input is sent to a server.
